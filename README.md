# ⭐ Projets principaux

## 🛡️ IDS/IPS basé sur le Machine Learning

Conception et développement d’un système intelligent de **détection et de prévention des intrusions réseau**, combinant des outils traditionnels de cybersécurité avec des techniques de Machine Learning.

### 🎯 Objectifs

- Surveiller le trafic réseau
- Détecter les activités suspectes
- Identifier différents comportements malveillants
- Exploiter le Machine Learning pour améliorer la détection
- Centraliser et visualiser les événements de sécurité

### 🛠️ Technologies

`Python` `Random Forest` `Snort` `OSSEC` `Django` `Nmap` `Metasploit`

### 🔍 Domaines

- Cybersécurité
- Sécurité réseau
- IDS / IPS
- Machine Learning
- Analyse du trafic réseau
